Clínica Boris - Sistema de Gestión de Pacientes

Sistema web desarrollado para la gestión de pacientes, pagos y administración de información médica para la Clínica Boris.  
El proyecto busca facilitar el manejo de pacientes, pagos de procedimientos y almacenamiento seguro de información clínica.

---

Descripción del Proyecto

Este sistema permite gestionar información relacionada con pacientes, procedimientos médicos y pagos dentro de una clínica.  
La aplicación está diseñada para ser escalable, segura y fácil de desplegar mediante contenedores.

Entre sus principales funciones se encuentran:

- Registro y gestión de pacientes
- Gestión de pagos de procedimientos
- Administración de información médica
- Almacenamiento de imágenes y datos clínicos
- Backend basado en API
